Projet Blinx
mai 2022 - décembre 2022,
mai 2023,
mai 2024 - août 2024
Le projet Blinx complète le projet CodeBoot .
Le but du projet CodeBoot est de créer une application web qui permet de programmer, surtout en Python, depuis un navigateur, sans rien installer côté client.
Le projet Blinx, c'est l'intégration de microcontrôleurs à cette application web, grâce à l' API Web Serial disponible sur Google Chrome (ainsi que sur Edge, Opera et les navigateurs basés sur Chromium).
L'objectif est de pouvoir contrôler un microcontrôleur (le Blinx) depuis l'application web CodeBoot.
Le projet est né avec la « réforme scolaire » au cégep, où la programmation devient obligatoire.
Mon superviseur voulait proposer CodeBoot aux cégeps comme outil d'apprentissage. Et Blinx est venu élargir les possibilités, en particulier pour les projets demandés.
Pendant l'été 2024, avec une deuxième bourse BRPC, j'ai développé une deuxième version de Blinx qui tient compte des problèmes rencontrés par les utilisateurs de la première, ce qui en a entièrement changé les fondations.
J'ai été supervisé par Marc Feeley, professeur à l'UdeM.
Le code de CodeBoot est sur GitHub, sur le compte de Marc Feeley et dans l'organisation codeBoot.
Langages utilisés pendant le stage :
  • Python
  • C++

Blinx Project
May 2022 - December 2022,
May 2023,
May 2024 - August 2024
The blinx project complements the CodeBoot project .
The aim of the CodeBoot Project is to create a web application that lets you do programming, especially Python, from a browser, without any client-side installation.
The blinx project is the integration of microcontrollers into the web application. Thanks to the web serial api available on Google Chrome (as well as on Edge, Opera, chromium base browser).
The aim is to be able to control a microcontroller (the blinx) from the codeboot web application.
The project saw the light of day with the "school reform" at CEGEP, where programming become a requirement.
My supervisor wanted to offer CodeBoot to CEGEP as a learning tool. And Blinx, came as an extension of the possibilities, especially for the project required.
During the summer of 2024, with a second USRA grant, I developed a second version of Blinx that takes into account the problems the users had met with the first one, which changed its foundations entirely.
I was supervised by Marc Feeley, professor at UdeM.
The code of CodeBoot is on GitHub, on Marc Feeley's account and in the codeBoot organisation.
Languages used during the course :
  • Python
  • C++
